# AGENTS.md

Цель: краткая справка для агентов/участников проекта по требованиям, примерам тестов, запуску проверок и ограничениям на изменения.

Проект и расположение
- Проект практики 4 расположен здесь: practices/practice_04/project
  - Пользователь сообщил о переносе в practice/practice-4. Если у вас именно такая структура, используйте её как PROJECT_ROOT. В текущем репозитории фактический путь: practices/practice_04/project.

- Структура UI и обязательные поля видны в шаблонах: PROJECT_ROOT/templates/{index.html,reports.html,thanks.html}.

Как запускать проверки
- Автоматических тестов для практики 4 нет. Используйте смоук-проверки вручную:
  1) Установка зависимостей (из корня репозитория):
     - python -m venv .venv
     - .venv\\Scripts\\pip install -r PROJECT_ROOT\\requirements.txt
  2) Запуск сервера:
     - .venv\\Scripts\\python PROJECT_ROOT\\server.py
  3) Смоук-проверки в браузере:
     - Открыть http://127.0.0.1:5000/ — форма отображается
     - Отправить форму (заполнить «Имя студента» и «Описание») — редирект на /thanks
     - Открыть /reports — заявка присутствует в списке
  4) Смоук-проверки через HTTP-клиент (опционально):
     - POST /report с form-data: name=Test, details=Hello — ожидать 302 Location: /thanks
     - GET /reports — код ответа 200 и HTML со списком

Части проекта, которые нельзя менять без разрешения
- Интерфейсы и контракты маршрутов сервера:
  - Пути и методы: GET /, POST /report, GET /thanks, GET /reports
  - Формат хранения: память процесса (без БД)
- Имена и расположение ключевых файлов в проекте практики 4:
  - PROJECT_ROOT/server.py
  - PROJECT_ROOT/templates/* (не переименовывать существующие шаблоны; можно добавлять новые при согласовании)
  - PROJECT_ROOT/requirements.txt (не добавлять тяжёлые/лишние зависимости без необходимости)
- Файлы верхнего уровня репозитория и других практик:
  - Makefile в корне (общие цели курса)
  - Каталоги practices/practice_01, practices/practice_02, practices/practice_03 — содержимое не изменять без запроса

Примечания
- Данные заявок не переживают перезапуск — это ожидаемо и является частью требований (нет БД).
- Если потребуется добавить новые фичи (например, экспорт или фильтрацию), согласуйте изменения маршрутов/шаблонов заранее и обновите документацию.
