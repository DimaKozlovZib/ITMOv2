# Quickstart: проверка UI модерации доносов

Этот документ описывает ручную проверку экранов. Реализация и задачи — в `tasks.md` (создаётся позже).

## Предусловия

- Зависимости из `practices/practice_04/project/requirements.txt` установлены в `.venv`.
- Контракт `practices/practice_05/contract.md` согласован.
- Логика (`server.py`) реализует маршруты из контракта. До этого проверяются только экраны, которые не
  зависят от новых маршрутов.

## Запуск

```powershell
.venv\Scripts\python practices\practice_04\project\server.py
```

Открыть `http://127.0.0.1:5000/`.

## Сценарии проверки

1. **Форма, пустые поля.** Отправить пустую форму. Ожидание: HTTP 422, под «Имя студента» текст «Укажите имя
   студента.», под «Описание» — «Опишите ситуацию.». Значения сохранены.
2. **Форма, длина имени.** Ввести «И» и отправить. Ожидание: «Имя студента: от 2 до 60 символов.».
3. **Форма, уровень.** Проверить, что в select есть `low`, `medium` (выбран по умолчанию), `high`.
4. **Форма, дубликат.** Отправить донос дважды с одинаковыми полями. Ожидание: блок над формой «Такой донос
   уже отправлен. Измените данные и отправьте снова.», значения сохранены.
5. **Экранирование.** Ввести `<b>тест</b>` в «Описание» и вызвать ошибку. Ожидание: в поле отображается
   текст `<b>тест</b>` без жирного шрифта.
6. **Благодарность.** Успешная отправка → `/thanks?id={id}` с номером. Открыть `/thanks` без `id` — текст-заглушка.
   Открыть `/thanks?id=99` — экран «Донос не найден».
7. **Список, пустой.** `/reports` без записей — «Пока пусто…», без фильтров и счётчика.
8. **Список, фильтры.** Фильтр по `vibe_level`, `group`, `q`, `status`. Значения полей сохраняются. При пустом
   результате — «Нет заявок, подходящих под фильтры.» и «Показано 0 из {total}».
9. **Счётчик.** «Показано X из Y» совпадает с числом записей на странице.
10. **Модерация.** «Подтвердить» у `new` → блок «Статус доноса №{id}: «Подтверждён».», бейдж обновлён.
    Кнопка «Подтвердить» у `confirmed` неактивна.
11. **Сохранение фильтров после действия.** Применить фильтр, нажать «Отклонить» — фильтр сохраняется.
12. **Экспорт.** Ссылки «Скачать CSV» и «Скачать JSON» открывают файл с учётом текущих фильтров.
13. **Неизвестный путь.** `/foo` → «Страница не найдена.».
14. **Некорректный параметр.** `/reports?status=pending` → «Некорректный запрос.».

## Проверка без браузера

Для шаблонов можно использовать тест-клиент Flask (skill `flask-api-check`): проверить HTTP-коды и наличие
текстов в ответе. Пример запуска:

```powershell
.venv\Scripts\python -c "import sys; sys.path.insert(0,'practices/practice_04/project'); from server import app; c=app.test_client(); print(c.get('/').status_code)"
```

## Критерии прохождения

- Все тексты совпадают с контрактом.
- Все коды HTTP совпадают с контрактом.
- Ни один пользовательский текст не выводится без экранирования.
- Страницы работают при отключённом JavaScript.
