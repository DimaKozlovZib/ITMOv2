# Data Model: Модерация доносов (UI)

Источник полей: `practices/practice_05/contract.md`, раздел «Единые определения». UI не создаёт и не
изменяет записи; он только выводит значения и отправляет действия.

## Запись доноса (получаемая UI)

| Поле | Тип | Источник | Как выводит UI |
|------|-----|----------|----------------|
| `id` | целое, положительное | логика | «№{id}», ссылка для действий, `changed_id`, `/thanks?id=` |
| `name` | строка 2–60 символов | логика | имя студента в записи |
| `group` | строка 0–20 символов, может быть пустой | логика | выводится, если не пусто |
| `details` | строка 10–1000 символов | логика | описание с переносами строк (`white-space: pre-wrap`) |
| `vibe_level` | `low` / `medium` / `high` | логика | бейдж: низкий / средний / высокий |
| `status` | `new` / `confirmed` / `rejected` | логика | бейдж: На рассмотрении / Подтверждён / Отклонён |
| `created_at` | дата-время UTC | логика | UI не выводит (нет в спеке UI) |

## Форма создания (отправляемая UI)

| Поле | Обязательность (UI) | Ограничение в HTML | Значение по умолчанию |
|------|---------------------|--------------------|-----------------------|
| `name` | обязательно (`required`) | `maxlength="60"` | пусто |
| `group` | необязательно | `maxlength="20"` | пусто |
| `details` | обязательно (`required`) | без `maxlength` | пусто |
| `vibe_level` | select | — | `medium` |

Серверные границы (контракт): `name` 2–60, `group` 0–20, `details` 10–1000 после обрезки.

## Фильтры списка (отправляемые UI)

| Параметр | Значения | По умолчанию |
|----------|----------|--------------|
| `status` | `all`, `new`, `confirmed`, `rejected` | `all` |
| `vibe_level` | `any`, `low`, `medium`, `high` | `any` |
| `group` | строка | пусто |
| `q` | строка | пусто |

## Состояния списка (вычисляются UI)

| Состояние | Условие | Что выводит UI |
|-----------|---------|----------------|
| Пустой список | `total = 0` | «Пока пусто. Оставьте первую заявку на главной странице.»; без фильтров и счётчика |
| Пустой результат фильтра | `total > 0` и `shown = 0` | «Нет заявок, подходящих под фильтры.»; фильтры и «Показано 0 из {total}» |
| Список с записями | `shown > 0` | записи, счётчик «Показано {shown} из {total}» |

## Состояния отправки формы (вычисляются по HTTP-коду)

| Состояние | HTTP | Что выводит UI |
|-----------|------|----------------|
| Ошибки полей | 422 | текст под каждым полем из `field_errors`; значения сохранены |
| Дубликат | 409 | блок над формой; значения сохранены |
| Внутренняя ошибка | 500 | блок над формой; значения сохранены |
| Успех | 302 | редирект на `/thanks?id={id}` |

## Переходы статусов (только для отображения кнопок)

| Текущий статус | «Подтвердить» | «Отклонить» |
|----------------|---------------|-------------|
| `new` | активна | активна |
| `confirmed` | `disabled` | активна |
| `rejected` | активна | `disabled` |

Переходы проверяет логика; UI лишь скрывает no-op через `disabled` по контракту.
