# Implementation Plan: Модерация доносов (сторона UI)

**Branch**: `001-report-moderation-ui` | **Date**: 2026-10-22 | **Spec**: `specs/001-report-moderation-ui/spec.md`

**Input**: Feature specification from `/specs/001-report-moderation-ui/spec.md`

**Contract**: `practices/practice_05/contract.md` (единственный источник маршрутов, полей, кодов и текстов)

## Summary

UI-часть модерации доносов: экраны на Flask/Jinja (форма, благодарность, список с фильтрами и модерацией,
«Донос не найден», «Некорректный запрос.», «Страница не найдена.»). Логика (валидация, дубликаты, переходы
статусов, счётчики, экспорт) находится в `server.py` и описана в контракте. План покрывает только
UI-шаблоны и минимальные изменения маршрутов, нужные для передачи данных шаблонам по контракту.

Подход: серверный рендеринг, нативные HTML-формы, без JavaScript. Тексты ошибок сопоставляются по кодам
из контракта в одном месте. Все значения выводятся через автоэкранирование Jinja2.

## Technical Context

**Language/Version**: Python 3.11 (по `__pycache__/server.cpython-311.pyc`)

**Primary Dependencies**: Flask>=3.0,<4 (`practices/practice_04/project/requirements.txt`); Jinja2 входит в Flask

**Storage**: память процесса (список `REPORTS`), без БД (конституция, принцип II)

**Testing**: ручные смоук-проверки по AGENTS.md; встроенный тест-клиент Flask (skill `flask-api-check`).
Автоматических тестов для практики 4 нет.

**Target Platform**: Windows, локальный сервер `127.0.0.1:5000`, браузер без JavaScript

**Project Type**: web-application (серверный рендеринг, одна папка `project/`)

**Performance Goals**: не задано; учебный проект, ограниченный объём данных в памяти

**Constraints**: без JavaScript; без БД; весь пользовательский текст на русском; экранирование всех значений;
тексты и коды только по контракту; новые шаблоны только при согласовании

**Scale/Scope**: 5 существующих шаблонов; при согласовании 2 новых (`not_found.html`, `error.html`); UI-маршрутов 6

**Justified violations**:

1. **Маршруты `/reports/{id}`, `/reports/{id}/status`, экспорт с фильтрами.** Конституция их не
   перечисляет. Контракт (раздел «Маршруты и ответы», примечание о совместимости) их согласовал. Нарушение
   обосновано контрактом. Конституцию стоит обновить отдельной поправкой (MINOR), это вне этой фичи.

2. **Путь контракта.** Конституция указывает `practice-05/contract.md` (через дефис), фактический путь
   `practices/practice_05/contract.md`. Это опечатка в конституции, не нарушение. Исправляется PATCH-поправкой.

**Gate result**: ERROR не возникает. Один пункт требует решения пользователя: новый шаблон `not_found.html`

## Phase 0: Research

`research.md` закрывает пункты, которые спека и контракт определяют не полностью:

- R1. Передача ошибок полей в шаблон формы (`fields[]` → словарь `field_errors`).
- R2. Сохранение значений формы при перерисовке (из `request.form`).
- R3. Где хранится словарь «код → текст» (один модуль/словарь в `server.py`).
- R4. Построение `return_query` и белого списка параметров для редиректа (Jinja `urlencode` принимает dict).
- R5. Шаблон «Донос не найден» и «Страница не найдена.»: отдельный файл или общий.
- R6. Атрибут `disabled` у текущей кнопки статуса и выбор текущего значения в `select`.

## Phase 1: Design

Артефакты: `data-model.md`, `contracts/ui-routes.md`, `quickstart.md`. Они описывают то, что UI получает
и выводит, и не дублируют контракт.
