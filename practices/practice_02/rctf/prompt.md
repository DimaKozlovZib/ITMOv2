КОНТЕКСТ
Работа ведётся с артефактом tests_load.md для проекта AI code review assistant.
Связанные ограничения и требования:
- API-1: diff размером более 20 000 символов должен приводить к HTTP 413.
- REL-1: таймаут LLM составляет 10 секунд.
- Подтверждённые источники: CASE.md, tests_integration.md, tests_unit.md, app/api.py, app/review_service.py.
- В tests_load.md уже описаны сценарии проверки границы размера diff и таймаута.

ТВОЯ ЗАДАЧА
Проанализируй текущий файл tests_load.md и предложи только обоснованные улучшения.
Для каждого сценария проверь три условия:
1. содержит ли он измеримый результат;
2. связан ли он с конкретным правилом репозитория;
3. указан ли Evidence с точной ссылкой на файл и строку.
Отдельно укажи, какие предложения нельзя подтвердить источниками.

ОГРАНИЧЕНИЯ
- Анализируй только предоставленные файлы.
- Не изменяй содержание без необходимости.
- Не добавляй новые требования, которых нет в исходных материалах.

ФОРМАТ ОТВЕТА
Ответ полностью на русском языке, разделён на четыре части:
1. Найденные проблемы и слабые места.
2. Обоснованные предложения по улучшению.
3. Evidence: ссылки на файлы и строки.
4. Предложения, которые нужно отклонить из-за отсутствия подтверждённых источников.

ТРЕБОВАНИЯ К ОФОРМЛЕНИЮ
- Не ломай структуру исходного файла tests_load.md: не меняй порядок разделов и колонок таблиц.
- Изменения показывай в формате, совместимом с текущей структурой файла (строки таблицы).
- Не переписывай весь файл без необходимости.
