# RAG

- Вопрос к источникам: какие конкретные числа (лимиты, таймауты, размеры diff) уже зафиксированы в правилах репозитория и в других тестовых файлах Практики 1, на которые можно опереться в нагрузочных сценариях вместо произвольных цифр?

## Разрешённые источники

| Файл или документ | Зачем нужен | Какой фрагмент используем |
|---|---|---|
| CASE.md | правила репозитория с числовыми ограничениями | API-1 (лимит diff 20 000 символов → HTTP 413), REL-1 (таймаут LLM 10 секунд) |
| tests_integration.md | уже согласованный граничный сценарий с конкретной цифрой | строка «Отправить diff длиной 21k → HTTP 413» (API-1; app/api.py:8–10) |
| tests_unit.md | проверяем, зафиксированы ли на уровне unit-тестов какие-либо числа, относящиеся именно к нагрузке (RPS, конкурентность, SLA по задержке) - а не только к SEC-1/OUT-1, которые числовых порогов нагрузки не содержат | строки SEC-1 и OUT-1 - используются как источник отрицательного результата, если числа нагрузки там не найдены |

[prompt.md](prompt.md)

## Ответ со ссылками на источники

```
Подтверждённые числа
20 000 — лимит размера diff (больше отклоняется с HTTP 413) | Evidence: CASE.md:65
10 секунд — таймаут внешнего вызова LLM | Evidence: CASE.md:66
 
Категории без подтверждения
RPS — источника нет
Конкурентность — источника нет
SLA по задержке — источника нет
```
