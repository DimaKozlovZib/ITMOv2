## Что уже совпадает

- Статусы: коды `new`, `confirmed`, `rejected` соответствуют подписям UI 1:1.
- Счётчик «Показано X из Y»: X = `shown`, Y = `total`.
- Пустой список (`total = 0`) и пустой фильтр (`shown = 0` при `total > 0`) вычисляются UI по этим полям.
- `GET /thanks` без `id` даёт `id=null`, UI показывает «Номер доноса не указан».
- Редирект после успешной отправки на `/thanks?id={id}`.
- Экранирование: UI выводит все значения экранированными; логика хранит их как введены.
- Значение «Все статусы» передаётся как `status=all` (или без параметра), «Любой уровень» как `vibe_level=any`.
