Чтобы запустить тесты, нужно выполнить команду из Makefile:
Файл: Makefile  
Строка: 3  
Команда: python3 -m unittest -v
Эта команда запускает модуль unittest в режиме подробного вывода.
Дополнительно: тесты находятся в файле test_service.py, который использует фреймворк unittest. В этом файле определены три тестовых случая:
- Тест на добавление подписчика (test_subscribe)
- Проверка ошибки при пустом имени (test_empty)
- Проверка отсутствия дублирования (test_duplicate)
Тесты запускаются автоматически при выполнении команды make test, как указано в README.md.
Файл: README.md  
Строка: 6  
Содержание: "Проверка: make test."
