Факт из service.py:  
- В файле L:\ITMOv2\practices\practice_03\lab\demo\service.py, строка 1:  
"subscribers = set()" — инициализирует пустое множество, которое хранится в памяти процесса.
Факт из test_service.py:  
- В файле L:\ITMOv2\practices\practice_03\lab\demo\test_service.py, строка 7:  
"subscribers.clear()" — при каждом запуске теста множество очищается, что подтверждает отсутствие сохранения состояния между вызовами.
Факт из README.md:  
- В файле L:\ITMOv2\practices\practice_03\lab\demo\README.md, строка 2:  
"Подписчики хранятся в памяти процесса." — явно указывает на то, что данные не сохраняются после перезапуска.
Вывод: Подписки хранятся только в памяти текущего процесса и удаляются при его завершении или перезапуске. Код подтверждает это поведение через использование set() без внешнего хранилища (файла, БД и т.д.).
