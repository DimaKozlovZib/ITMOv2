Чтобы запустить тесты, необходимо выполнить команду:
make test
Эта команда определена в файле Makefile на строке 3.  
Файл: Makefile, строка: 3
Дополнительно:
- Тесты реализованы в файле test_service.py, где используется модуль unittest.
- В тестах проверяется корректность функции subscribe() из файла service.py (строки 5–21 в test_service.py).
- Файл README.md указывает на запуск тестов командой make test на строке 6.
Таким образом, для запуска тестов следует использовать make test.
