В коде service.py при пустом имени подписчика (или имени, содержащем только пробелы) вызывается ошибка:
- На строке 5: if not name.strip(): — проверяется, является ли имя пустым или содержимым только пробелами.
- Если условие выполняется (name.strip() возвращает пустую строку), то на строке 6 возникает исключение: raise ValueError("empty name").
Таким образом, при пустом имени подписчика (или только пробелы) будет выброшено исключение с текстом "empty name".
Файл: service.py, Строки: 5–6.
