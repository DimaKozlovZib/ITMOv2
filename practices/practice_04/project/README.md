Проект: Форма доносов на студентов, которые «вайбкодят»

Состав:
- Сервер: Python + Flask, без БД (данные держатся в памяти до перезапуска)
- Клиент: простые HTML-страницы с формой

Запуск (Windows, PowerShell):
1. Установите зависимости:
   python -m venv .venv
   .venv\\Scripts\\pip install -r "практики 4\\requirements.txt"
2. Запустите сервер:
   .venv\\Scripts\\python "практики 4\\server.py"
3. Откройте в браузере:
   http://127.0.0.1:5000/

Маршруты:
- / — форма отправки доноса
- /report (POST) — приём формы
- /thanks — страница-ответ после отправки
- /reports — список всех отправленных доносов (хранится в памяти)

Примечание:
- Данные очищаются при перезапуске сервера, так как БД не используется.
